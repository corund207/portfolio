# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The portfolio serves recruiters, engineering teams, potential collaborators, and clients evaluating Jonah Chang's technical ability, judgment, and range.

## Product Purpose

Present Jonah's strongest work in robotics, motion control, computer vision, AI, and web development. Success means a visitor quickly understands what Jonah builds, sees credible technical evidence, explores relevant projects, and has a clear path to make contact.

## Positioning

Jonah builds software that crosses the boundary between computation and the physical world: robotics control systems, traditional robotic arms, on-screen computer vision, gesture interfaces, simulations, and developer tooling.

## Operating Context

Visitors arrive from GitHub, applications, referrals, or shared links and often evaluate the portfolio quickly on desktop or mobile. GitHub repositories, live documentation, project imagery, and concise technical explanations are the primary evidence.

## Capabilities and Constraints

- Single-page static web portfolio with no required build step.
- Project data may refresh from the public GitHub API and must retain a useful local fallback.
- Existing factual projects, public repository links, email address, and live documentation links should remain available.
- The current LinkedIn URL is an unresolved placeholder and must not be presented as a working destination.
- The experience must remain useful when JavaScript, animation, the GitHub API, or external imagery is unavailable.

## Brand Commitments

- Name: Jonah Chang.
- Voice: technically precise, direct, curious, and grounded in real work.
- The user requested a complete overhaul with a dramatic improvement across the full experience rather than a conservative refinement.

## Evidence on Hand

- Public repositories at `https://github.com/jonahchang207`.
- Existing project descriptions and fallback data in `index.html`.
- Odyssey repository and documentation links.
- Real repository screenshots, diagrams, and project artwork stored locally for resilient project thumbnails.
- No verified testimonials, employers, clients, performance benchmarks, portrait photography, résumé, or valid LinkedIn URL are currently present; future work must not fabricate them.

## Product Principles

- Lead with demonstrated work, not generic self-description.
- Make technically complex projects understandable without flattening their depth.
- Treat motion as an explanatory material, especially for robotics and control systems.
- Give every audience a fast path from first impression to credible evidence.
- Preserve truth and graceful fallback behavior while making the presentation ambitious.

## Accessibility & Inclusion

Support keyboard navigation, visible focus states, semantic structure, readable contrast, reduced-motion preferences, and responsive layouts from small mobile screens through wide desktops.
